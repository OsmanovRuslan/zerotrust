# ZeroTrust Module

Универсальный программный модуль реализации архитектуры нулевого доверия (Zero Trust,
NIST SP 800-207) в микросервисных приложениях на Spring Boot.

Магистерская ВКР, ДГТУ, 09.04.04 «Программная инженерия». Автор — Османов Р. М.
Научный руководитель — к.т.н., доцент Атаян А. М.

## Состав проекта

| Модуль | Содержимое |
| --- | --- |
| `zerotrust-core` | Чистая Java 21: модель, математическая модель доверия, движок решения. Без Spring |

Автоконфигурация Spring Boot и стартер добавляются следующими модулями.

## Сборка

Нужен JDK 21. Сборка — через Maven Wrapper:

```bash
JAVA_HOME=/path/to/jdk-21 ./mvnw clean verify
```

```powershell
$env:JAVA_HOME='C:\Java\jdk-21'; .\mvnw.cmd clean verify
```
